API Reference

All chat endpoints require Authorization: Bearer <accessToken>.

Authentication

POST /api/auth/register

{
  "email": "user@example.com",
  "password": "secret123",
  "role": "user"
}

POST /api/auth/login

{
  "email": "user@example.com",
  "password": "secret123",
  "role": "user"
}

Chat Routes

  • GET /api/chat/contacts
  • POST /api/chat/conversations
  • GET /api/chat/conversations?page=1&limit=20
  • GET /api/chat/conversations/:conversationId/messages?limit=200
  • POST /api/chat/conversations/:conversationId/messages
  • POST /api/chat/conversations/:conversationId/read

Create Conversation

{
  "recipientId": "CONTACT_ID",
  "recipientModel": "Doctor"
}

Send Message

{
  "content": "Hello there"
}

Socket Events

  • chat:message: emitted when a new message is delivered
  • chat:read: emitted when a conversation is marked as read

The socket client authenticates with the same JWT token used for the REST API.
