Installation Guide

This item ships as two projects:

  • /: backend API and Socket.IO server
  • /client: Next.js frontend client

Backend Setup

  1. Open the root project folder.
  2. Run npm install.
  3. Copy .env.example to .env.
  4. Update MONGO_URI, ACCESS_TOKEN_SECRET, REFRESH_TOKEN_SECRET, and FRONTEND_URL.
  5. Run npm run dev.
PORT=5000
MONGO_URI=mongodb://localhost:27017/role-based-chat
FRONTEND_URL=http://localhost:3000
ACCESS_TOKEN_SECRET=replace-with-a-long-random-secret
REFRESH_TOKEN_SECRET=replace-with-a-long-random-secret
ACCESS_TOKEN_EXPIRY=15m
REFRESH_TOKEN_EXPIRY=7d

Frontend Setup

  1. Open client.
  2. Run npm install.
  3. Copy .env.example to .env.local.
  4. Start the app with npm run dev.
NEXT_PUBLIC_API_BASE_URL=http://localhost:5000
NEXT_PUBLIC_CHAT_API_URL=http://localhost:5000/api
NEXT_PUBLIC_SOCKET_URL=http://localhost:5000

Default Routes

  • /login: sign in
  • /register: create an account
  • /inbox: conversations and message workspace
  • /health: backend health check

Production Notes

  • Use HTTPS in production.
  • Replace all secrets with long random values.
  • Set FRONTEND_URL to your deployed frontend domain.
  • Build the backend with npm run build.
  • Build the frontend with npm run build inside client.
